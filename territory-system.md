# Territory System

Territory files define the map zones where animal and zombie populations spawn. Each creature type has its own territory file inside `env/`.

| File | What It Controls |
|---|---|
| [territories.xml](14_territories_xml.md) | Zone definitions per creature type |

> **Path:** `dayzxb_missions/dayzOffline.<mapname>/env/` (Xbox) · `dayzps_missions/…` (PlayStation)
>
> One file per creature: `bear_territories.xml`, `wolf_territories.xml`, `zombie_territories.xml`, etc.
